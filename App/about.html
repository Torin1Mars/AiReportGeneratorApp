Report generator guideline

Report generator workflow :

From your files to a finished report in five steps

  1. Pick a template

    The file that sets the report's structure.

  2. Add reports and explanation docs

    Reports are what gets analysed; explanation docs give context.

  3. Prepare data

    Reads and packs your files for the AI.

  4. Set up generation

    Add a prompt, choose the language. Open ⚙ to set the API key, model and style.

  5. Generate report

    Follow progress in the status line.
